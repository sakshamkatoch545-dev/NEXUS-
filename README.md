# 🤖 AI Profile Detector

A machine learning-powered tool that analyzes profile images to detect AI-generated or fake profiles using image symmetry analysis and CLIP embeddings.

## 🚀 Features
- Detects AI-generated profile pictures
- Analyzes facial symmetry
- CLIP-based image embeddings
- Simple Streamlit web interface

## 🛠️ Tech Stack
- Python
- OpenCLIP
- Streamlit
- NumPy
- OpenCV

## ⚙️ Installation

\\\ash
git clone https://github.com/sakshamkatoch545-dev/ai-profile-detector.git
